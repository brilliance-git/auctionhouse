# Wowhead (WoW: Forever) drop tables: rest of Scarlet Monastery, Razorfen Downs, Razorfen Kraul (2026-11-25)

This file uses the same source and format as `wowhead-drops-classic-2026-11-25.md`: wowhead.com/forever NPC "Drops" tabs, listing every mob with at least one blue drop and at least 20 recorded kills. Each dungeon is a candidate farm for a level-60 character.

How to read an entry:
- "(low blue rate)" means fewer than 0.5 blues per kill.
- "greens N%" is the expected number of greens per kill. It can be above 100%, meaning more than one green per kill on average.

Bind type isn't in this data. Look the item IDs up on the Horde AH: an item that has ever been listed there is bind-on-equip.

Scarlet Monastery's Houndmaster Loksey and Interrogator Vishas are in `wowhead-drops-classic-3-2026-11-25.md`. Together with this file, Scarlet Monastery is complete.

Not collected: Roogug (Razorfen Kraul, npc 6168), City of Dalaran and Ruins of Lordaeron. Wowhead's human-verification check stopped the collection again, after 28 pages.
