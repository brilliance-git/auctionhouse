# Wowhead (WoW: Forever) drop tables: Dire Maul and Maraudon (2026-11-25)

This file uses the same source and format as `wowhead-drops-classic-2026-11-25.md`: wowhead.com/forever NPC "Drops" tabs, listing every mob with at least one blue drop and at least 20 recorded kills.

How to read an entry:
- "(low blue rate)" means fewer than 0.5 blues per kill.
- "greens N%" is the expected number of greens per kill. It can be above 100%, meaning more than one green per kill on average.

Bind type isn't in this data. Look the item IDs up on the Horde AH: an item that has ever been listed there is bind-on-equip.

Not collected: Uldaman, Zul'Farrak, Razorfen Downs, Scarlet Monastery, Razorfen Kraul, City of Dalaran and Ruins of Lordaeron. Wowhead's human-verification check stopped the collection again.
